# Mydoors

[![ContentDB](https://content.luanti.org/packages/Don/mydoors/shields/downloads/)](https://content.luanti.org/packages/Don/mydoors/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
_[Forum Topic](https://forum.luanti.org/viewtopic.php?t=10626)_

Mydoors is a modpack with many door styles. Adds over 50 doors to Luanti/Minetest.
It is set up as a mod pack so you can choose the style of doors you want without adding them all.
It has everything from old fashion doors to futuristic sliding doors.

## Dependencies

- Luanti/Minetest v0.4.10
- MTG mods `default`, `doors`, `flowers`, `wool`

### Optional Dependencies

- MTG mods `stairs` and `screwdriver`
- [More Blocks](https://github.com/minetest-mods/moreblocks)
- [Basic Materials](https://github.com/mt-mods/basic_materials)
